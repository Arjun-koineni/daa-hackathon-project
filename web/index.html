1. Component Partitioning

Recursive DFS starts from vertex 0..n-1 if unvisited. All reachable vertices receive the root label v. Component count equals the number of DFS launches.

2. Ascending Neighbor Tie-Breaking

Every adjacency list is sorted ascending before any exploration. This guarantees determinism in recursive DFS order and BFS discovery queues.

3. BFS Mark on Enqueue

Vertices are marked and their distance and parent set immediately upon enqueueing, ensuring shortest paths and preventing duplicate entries.

4. Route Backtracking

Routes are reconstructed by following the parent[] pointers back from target t to source s and reversing the path list.
